# Question images

Images for questions that use them. The rules are under "Images" in [docs/QUESTION-SCHEMA.md](../../docs/QUESTION-SCHEMA.md).

- Name each file after its question: `<question id>-<n>.<ext>`, for example `cr02-s04-1.jpg`.
- Upload images here (open this folder on GitHub, then **Add file**, then **Upload files**).
- A question whose image isn't here yet is held back from the live site until it is.
